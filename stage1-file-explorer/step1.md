# 📍 步驟一：情報搜集 —— 認識你的新辦公桌

歡迎來到 Linux 的世界！這個黑底白字的視窗叫做 **Shell（命令列介面）**。不要被它嚴肅的外表嚇到了，它其實就是一個「只聽指令辦事」的超高效祕書。

既然主管丟了一堆檔案過來，動手分類前，我們先用三個基本動作來摸清狀況：

### 1. 檢查我的權限：我是誰？
在辦公室裡分清身分很重要。點擊下方指令，確認你目前在系統裡的行政身分：
`whoami`{{execute}}
> 💡 **小撇步：** 在 Killercoda 裡，你不需要自己辛苦打字。只要「用滑鼠點一下」上面這個灰色的指令方塊，它就會自動幫你打進右邊的黑視窗並執行喔！

### 2. 確認位置：我在哪裡？
Windows 有黃色的資料夾圖示，Linux 則是用「路徑字串」來告訴你你目前站在電腦的哪一個角落。輸入代表 Print Working Directory（列出工作目錄）的縮寫：
`pwd`{{execute}}
> 畫面上顯示的 `/root` 或 `/home`，就是你目前的「桌面位置」。

### 3. 清點檔案：這裡有什麼？
主管丟過來的專案資料在哪裡？我們用 `ls`（List，清單）這個指令來偷看辦公桌上有什麼檔案：
`ls`{{execute}}

你應該會看到一個叫做 `confusing_project`（混亂的專案）的資料夾。找到了！接下來，我們要施展空間瞬移跳進去。請點擊右下角按鈕進入下一步！
