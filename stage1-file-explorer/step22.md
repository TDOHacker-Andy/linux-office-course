# Step 22：更新軟體清單——apt update

在正式安裝任何工具之前，我們得先認識 Linux 安裝軟體的方式，跟你熟悉的 Windows 完全不同。

## 🤔 跟 Windows 安裝軟體有什麼不同？

在 Windows 上，你通常要自己上網搜尋「XX 軟體下載」，點進某個網站，下載一個安裝檔，過程中常常一不小心就點到偽裝成下載按鈕的廣告，結果中毒或裝了一堆有的沒的工具列。

Linux 的做法完全不同：系統背後有一個官方維護的「軟體倉庫」，所有你要的工具都從這個可信任的來源直接安裝，**不會有廣告，也不需要自己上網亂找**。

這個系統在 Ubuntu／Debian 系列的 Linux 上，叫做 `apt`（*Advanced Package Tool*，進階套件工具）。

## 🔹 指令：apt update——先更新「軟體目錄清單」

在安裝任何東西之前，建議先執行這個指令：

`sudo apt update`{{execute}}

這個指令在做的事情是：去跟軟體倉庫的伺服器確認一次，「目前有哪些軟體、各自的最新版本是什麼」，並且把這份清單更新到你的電腦裡。

> 💡 用一個比喻來理解：這就像你去圖書館借書之前，先看一眼最新的館藏目錄，確認你要的書有沒有到貨、是不是最新版，而不是直接走進書庫亂翻。

`apt update` 本身**不會安裝或更新任何軟體**，它只是更新「目錄清單」而已，下一站我們才會真正動手安裝東西。

## ⚠️ 為什麼前面要加 sudo？

安裝、更新軟體會牽涉到修改系統層級的檔案，這是只有管理員才能做的事，所以需要借用 Step 18 學過的 `sudo`。
