# Step 25：建立基礎資料

確認你在專題資料夾裡：

`cd ~/booking_system`{{execute}}

## 🔹 建立會議室清單

我們用 `nano` 來建立這份檔案（複習 Step 7 學過的編輯器操作：打字輸入內容後，按 `Ctrl+O` 存檔、`Enter` 確認、`Ctrl+X` 離開）：

`nano data/rooms.txt`{{execute}}

請輸入以下內容（每行一間會議室，格式是「房號,名稱,容納人數,設備」）：

```
A,A會議室,6,白板
B,B會議室,10,投影機+白板
C,C會議室,20,投影機+視訊設備
```

如果你不想用 `nano` 手動輸入，也可以用以下一行指令直接產生同樣的檔案：

`printf "A,A會議室,6,白板\nB,B會議室,10,投影機+白板\nC,C會議室,20,投影機+視訊設備\n" > data/rooms.txt`{{execute}}

確認內容：

`cat data/rooms.txt`{{execute}}

## 🔹 建立可外借設備清單

`printf "PJ-01,投影機 01,可外借\nPJ-02,投影機 02,可外借\nLT-01,筆記型電腦 01,可外借\n" > data/equipment.txt`{{execute}}

`cat data/equipment.txt`{{execute}}

## 🔹 建立借用紀錄表，先寫好「表頭」

這是整個系統最核心的檔案。我們先只建立「表頭」（也就是欄位名稱），之後每一筆借用紀錄都會新增一行在它下面：

`echo "日期,時段,項目,借用人,部門,登記時間,狀態" > data/bookings.csv`{{execute}}

確認一下：

`cat data/bookings.csv`{{execute}}

> 💡 注意這裡用的是單一個 `>`（不是 `>>`），代表「建立新檔案／覆蓋整份內容」。等一下我們新增借用紀錄時，會改用 `>>`（兩個角括號），代表「在檔案最後面追加一行，不會把原本的內容洗掉」，這個差異請務必記住，用錯會把整份紀錄洗掉。
