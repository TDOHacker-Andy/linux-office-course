# Step 17：修改權限——chmod 數字法

知道怎麼「看懂」權限之後，這一站要學怎麼「動手修改」它。

## 🔹 先把 rwx 翻譯成數字

`chmod` 最常用的寫法是用數字，每一組 `rwx` 都可以換算成一個 0~7 的數字：

| 權限組合 | 數字 | 為什麼 |
|---|---|---|
| `rwx` | 7 | r(4) + w(2) + x(1) = 7 |
| `rw-` | 6 | r(4) + w(2) = 6 |
| `r-x` | 5 | r(4) + x(1) = 5 |
| `r--` | 4 | r(4) = 4 |
| `---` | 0 | 完全沒有權限 |

口訣：**r = 4，w = 2，x = 1**，有就加，沒有就不加。

一個完整的權限數字會是 3 碼，分別代表「擁有者、同群組、其他人」，例如 `600` 就是「擁有者 = 6（讀+寫），同群組 = 0（無），其他人 = 0（無）」。

## 🔹 實戰：把薪資相關週報鎖進保險箱

工讀生週報裡其實含有跟人事相關的資訊，不該讓其他帳號隨意讀取。先看一下目前的權限：

`ls -l part_time_weekly_report.txt`{{execute}}

執行修改：

`chmod 600 part_time_weekly_report.txt`{{execute}}

再看一次：

`ls -l part_time_weekly_report.txt`{{execute}}

你應該會看到變成 `-rw-------`，代表現在**只有擁有者自己**可以讀寫這份檔案，同群組跟其他人完全看不到、也動不了。

## 🔹 常見的權限數字組合速查

| 數字 | 用途 |
|---|---|
| `600` | 機密檔案：只有自己能讀寫，其他人完全看不到 |
| `644` | 一般檔案：自己能讀寫，其他人只能看不能改（最常見的預設值） |
| `700` | 機密資料夾：只有自己能進入、讀寫 |
| `755` | 一般資料夾：自己能完全操作，其他人能進入查看但不能修改 |

## 🔹 練習：把 archive 資料夾設成「自己能完全操作，其他人只能看」

`chmod 755 archive`{{execute}}

`ls -ld archive`{{execute}}

你應該會看到 `drwxr-xr-x`——對照剛剛那張速查表，這正是 `755` 的結果。
