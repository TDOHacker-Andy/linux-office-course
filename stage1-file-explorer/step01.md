# Step 1：這個黑黑的畫面到底是什麼？

歡迎來到這堂課！如果你完全沒有寫過程式、沒碰過 Linux，**這正是為你設計的起點**，請放心，我們會非常慢、非常仔細地一步一步來。

## 🖥️ 這個畫面叫做「終端機」

你現在看到的這個黑底（或深色底）的畫面，叫做**終端機（Terminal）**。

你可以把它想成是「文字版的滑鼠」。平常你用滑鼠點兩下開啟資料夾、點兩下開啟檔案；在終端機裡，你是用「打字」來做同樣的事情，只是更快、更精準，而且可以一次處理成千上萬筆資料。

## ⌨️ 什麼是「指令」？

你在終端機裡打的每一行字，叫做**指令（Command）**。一行指令通常長這樣：

```
指令名稱 選項 目標
```

舉例來說，等一下我們會學到的 `ls -l /root`，拆開來看：

- `ls`：指令名稱（這個指令的功能是「列出清單」）
- `-l`：選項（用來調整指令的顯示方式，通常用 `-` 開頭）
- `/root`：目標（你要對哪裡、哪個檔案做這件事）

不是每一行指令都有選項或目標，但結構大致就是這樣。**完全不用死背**，我們會在每一站實際操作中慢慢累積熟悉感。

## 🤔 為什麼行政人員要學這個？

你可能會想：「我又不是工程師，學這個做什麼？」

老實說，這堂課不是要把你訓練成工程師。而是因為很多每天讓你頭痛的瑣事——例如：

- 一次建立幾十個資料夾
- 在幾千行的 Excel 報表裡找特定的幾筆資料
- 把一整份文件裡的某個字全部換掉
- 管理「誰可以看這份檔案、誰不行」

這些事情用滑鼠點，可能要花你半小時甚至更久；但用本課程教的指令，往往只要**一行字、幾秒鐘**。

學完這堂課，你會親手做出一個「會議室/設備借用登記系統」，這是一個你下課後可以直接帶回辦公室使用、也可以拿去跟主管展示的真實成果。
