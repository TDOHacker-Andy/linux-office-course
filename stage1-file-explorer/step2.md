# ⚡ 步驟二：空間瞬移與一秒建檔魔法

用滑鼠時，我們要點兩下才能進入資料夾。在 Linux 裡，我們用指令直接「瞬移」。

### 1. 空間瞬移進入專案
使用 `cd`（Change Directory，切換目錄）指令，直接跳進那個混亂的專案資料夾：
`cd confusing_project`{{execute}}

進來之後，再次確認我們真的移過來了：
`pwd`{{execute}}
> 沒錯！路徑後面多了 `/confusing_project`，你成功瞬移了！

### 2. 施展外掛：一秒建立 12 個月份資料夾
主管要求建好 1-12 月的專案資料夾。
以前你要點右鍵 12 次、改名 12 次。現在，請見證 Linux 指令的真正威力！

我們使用 `mkdir`（Make Directory，建立目錄），加上樂高積木般的「大括號 `{}`」魔法：
`mkdir 專案_{01..12}月`{{execute}}

執行完了！好像什麼事都沒發生？別急，我們用剛剛學到的「清點辦公桌」指令檢查看看：
`ls`{{execute}}

看見了嗎？**專案_01月、專案_02月 ... 到 專案_12月**，12 個資料夾在一眨眼間整整齊齊地排好！耗時 0.1 秒！

這就是鍵盤流的威力。你離週五準時下班只剩最後一步了！
