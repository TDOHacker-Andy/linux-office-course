# ⚡ 步驟二：空間瞬移與一秒建檔魔法

主管要我們處理的藍色資料夾已經在桌上了。以前用滑鼠時，我們要用手指點兩下才能進入資料夾；在 Linux 裡，我們直接用指令「瞬移」過去。

---

### ⌨️ 動手練習 4：空間瞬移進入專案
請在右邊黑色視窗中，手打輸入以下指令並按下 **Enter**：

```bash
cd confusing_project
```{{execute}}

> 💡 **執行完後，請觀察你的游標左邊：**
> 你會發現提示字變成了 `root@ubuntu:~/confusing_project#`，代表你人已經成功走進這個專案房間了！
> 
> 接下來，我們一樣可以輸入 `ls` 來清點這個房間內的報表檔案：
> ```bash
> ls
> ```{{execute}}

---

### ⌨️ 動手練習 5：影分身之術！一秒建立 12 個月份資料夾
主管交代了最後一項緊急任務：
*「為了下週的年度業務總體檢，請幫我在這個專案裡把 1 到 12 月的專案資料夾通通建立好！」*

以前用滑鼠，你得在資料夾裡重複「按右鍵 -> 新增資料夾 -> 重新命名」這套動作整整 12 次。現在，請優雅地手打輸入這一行專業的 Linux 組合指令（注意大括號中間是**兩個英文句點**哦）：

```bash
mkdir project_month_{01..12}
```{{execute}}

> 💡 **這行指令代表什麼意思？**
> `mkdir` 是 **M**ake **D**irectory（建立資料夾）的縮寫。
> 而 `{01..12}` 則是 Linux 祕書最厲害的自動連續技，它會自動幫你從 01 數到 12。
> 
> 執行完後，請再次輸入 `ls` 檢查看看：
> ```bash
> ls
> ```{{execute}}
> 
> 看到了嗎？**project_month_01 到 project_month_12**，12 個業務資料夾在 0.1 秒內整整齊齊地一字排開，沒有任何歪斜！你成功用一行指令，解救了禮拜五下午想準時下班的自己！
