# ⚡ 步驟二：空間瞬移與一秒建檔魔法

以前用滑鼠時，我們要用手指點兩下才能進入資料夾。在 Linux 裡，我們直接用指令「瞬移」過去。

### 1. 空間瞬移進入專案
使用 `cd`（Change Directory，切換目錄）指令，直接跳進那個混亂的專案資料夾裡：
`cd confusing_project`{{execute}}

進來之後，再次確認我們真的移過來了：
`pwd`{{execute}}
> 沒錯！路徑後面多了 `/confusing_project`，你成功瞬移了！

### 2. 影分身之術：一秒建立 12 個月份資料夾
主管要求建好 1-12 月的專案資料夾。
以前你要點右鍵 12 次、改名 12 次。現在，請體驗 Linux 真正吸引人的地方。

我們使用 `mkdir`（Make Directory，建立目錄），加上一組「大括號 `{}`」的規律魔法：
`mkdir 專案_{01..12}月`{{execute}}

執行完了！好像什麼事都沒發生？別急，我們用剛剛學到的「清點辦公桌」指令檢查看看：
`ls`{{execute}}

看見了嗎？**專案_01月、專案_02月 ... 到 專案_12月**，12 個資料夾在 0.1 秒內整整齊齊地排好！

這只是單次下指令的威力。試著想像一下：如果把今天學到的所有指令像寫劇本一樣寫進一個檔案，以後遇到這種事，連這一行行字都不用打，一鍵就能全部跑完。

你離週五準時下班又更近一步了，點擊右下角按鈕完成本關！
