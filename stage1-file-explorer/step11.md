# Step 11：刪除的勇氣與風險——rm / rmdir

這是整個模組裡，**唯一一個我要請你在動手之前，先花時間讀完整篇說明**的指令。原因很簡單：它是這堂課裡唯一一個「沒有反悔機會」的操作。

## ⚠️ 最重要的觀念，請先記住

> **Linux 的刪除指令沒有資源回收筒。**
>
> 在 Windows 上刪錯檔案，你還可以打開資源回收筒撿回來。但在 Linux 的終端機裡，`rm` 指令一旦執行成功，檔案是**立即、直接、永久消失**，沒有任何「復原」按鈕。

正因為如此，請養成一個習慣：**執行刪除指令前，先用 `ls` 看一次，確認你要刪的東西、跟你打的路徑，是同一個。**

## 🔹 指令：rm——刪除檔案

我們先刪除一份真的用不到的檔案（Step 9 建立的備份，現在練習完了可以清掉）：

`ls`{{execute}}

`rm part_time_weekly_report_backup.txt`{{execute}}

確認一下，它真的消失了：

`ls`{{execute}}

## 🔹 指令：rmdir——只能刪除「空」資料夾

`rmdir` 是 *Remove Directory*（刪除目錄）的縮寫，但它有一個重要限制：**只能刪除完全空的資料夾。**

`rmdir test_folder`{{execute}}

你應該會看到一個錯誤訊息，類似 `Directory not empty`（資料夾不是空的）——因為我們前幾站已經在 `test_folder` 裡放了好幾份檔案。`rmdir` 這個限制其實是一種保護機制：它逼你必須先確認資料夾裡沒有重要東西，才能刪除。

## 🔹 指令：rm -r——連同資料夾裡所有內容一起刪除

如果你確定要把一整個資料夾（連同裡面所有檔案）都刪掉，要加上 `-r`（遞迴）：

`rm -r test_folder`{{execute}}

確認一下：

`ls`{{execute}}

`test_folder` 已經完全消失，包含它裡面原本的所有檔案。

## 🛡️ 給新手的安全建議

1. **刪除前先 `ls` 確認**，尤其是要刪的東西路徑比較複雜的時候。
2. **不確定的話，先用 `mv` 把東西搬到一個叫 `_待確認刪除` 的資料夾裡，觀察個幾天，確定不會用到了再真的 `rm`。**
3. **絕對不要因為求快，把 `rm -r` 後面接一個很模糊、自己沒看清楚的路徑。** 永遠記得：這個指令沒有後悔藥。
