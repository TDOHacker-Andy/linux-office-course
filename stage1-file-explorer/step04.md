# Step 4：移動位置——走進房間、走出房間

## 🔹 指令：cd（切換位置）

`cd` 是 *Change Directory*（切換目錄）的縮寫，用法是 `cd 資料夾名稱`：

`cd office_drill`{{execute}}

確認一下你現在的位置：

`pwd`{{execute}}

你應該會看到 `/root/office_drill`。再看看裡面有什麼：

`ls`{{execute}}

## 🔹 走回上一層

剛剛 Step 3 提到，`..` 代表「上一層資料夾」。我們現在來實際使用它：

`cd ..`{{execute}}

`pwd`{{execute}}

你應該又回到 `/root` 了。

## 🔹 幾個你一定會用到的路徑捷徑

| 符號 | 意思 |
|---|---|
| `~` | 你的家目錄（對你來說等於 `/root`） |
| `.` | 目前所在的資料夾 |
| `..` | 上一層資料夾 |
| `/` | 整台電腦最頂層的根目錄 |

試試看，不管你現在在哪裡，這個指令都能讓你瞬間回到家：

`cd office_drill`{{execute}}

`cd ~`{{execute}}

`pwd`{{execute}}

> 💡 **小技巧**：如果你打 `cd` 後面什麼都不加，效果跟 `cd ~` 一樣，都是回家。

## ⚠️ 新手常見錯誤

- **打錯資料夾名稱**：Linux 對英文「大小寫」很敏感，`Office_drill` 跟 `office_drill` 是兩個不同的名字，打錯會出現 `No such file or directory`（找不到這個檔案或資料夾）的錯誤訊息，這完全正常，重新打一次路徑即可。
- **資料夾名稱有空白**：如果資料夾名字中間有空格，必須用引號包起來，例如 `cd "My Folder"`，否則系統會誤以為你是要切換到兩個不同的地方。
