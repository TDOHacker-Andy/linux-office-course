# Step 21：系統的人事總名簿——/etc/passwd

每一個你在系統上建立過的帳號，其實都被記錄在一份固定的檔案裡，這一站我們來看看它。

## 🔹 指令：查看 /etc/passwd

`cat /etc/passwd`{{execute}}

你會看到一長串資料，每一行代表一個帳號。畫面可能有點多，我們搭配 Step 13 學過的 `grep`，只篩選出剛剛新增的 `intern_demo`：

`grep intern_demo /etc/passwd`{{execute}}

你應該會看到類似這樣一行：

```
intern_demo:x:1001:1001::/home/intern_demo:/bin/sh
```

## 🔹 拆解這一行的意思

這一行用 `:` 分隔成好幾個欄位，從左到右分別是：

| 欄位 | 範例內容 | 意思 |
|---|---|---|
| 1 | `intern_demo` | 帳號名稱 |
| 2 | `x` | 密碼欄位（實際密碼加密後存在別的檔案，這裡只是顯示一個 `x` 佔位） |
| 3 | `1001` | 使用者 ID（UID），系統內部用來識別這個帳號的數字編號 |
| 4 | `1001` | 所屬群組 ID（GID） |
| 5 | （通常是空的或帳號全名） | 備註欄 |
| 6 | `/home/intern_demo` | 這個帳號的家目錄位置 |
| 7 | `/bin/sh` | 這個帳號登入後預設使用的 Shell（終端機程式） |

## 🔹 看看自己的帳號

`whoami`{{execute}}

`grep root /etc/passwd`{{execute}}

對照看看，跟剛剛 `intern_demo` 的那一行，欄位結構是不是一模一樣？

> 💡 **行政人員視角**：以後不管是要確認「公司系統裡到底有幾個帳號」，還是「這個帳號的家目錄到底放在哪裡」，`/etc/passwd` 就是最直接的答案來源，不需要再憑印象猜測。
