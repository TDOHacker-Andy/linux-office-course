# Step 32：終極整合——把整套系統包裝成一個選單

`cd ~/booking_system`{{execute}}

到目前為止，你已經有 4 個各自獨立的腳本：新增、查詢、統計、取消。這一站，我們要把它們包裝成「一個入口、選單操作」的系統，讓任何人（包含完全不懂指令的同事）都能輕鬆使用。

## 🔹 撰寫主選單腳本

`nano scripts/booking_manager.sh`{{execute}}

輸入以下內容：

```bash
#!/bin/bash
cd "$(dirname "$0")/.."

while true; do
  clear
  figlet -f small "Booking System" 2>/dev/null || echo "=== 會議室/設備借用登記系統 ==="
  echo ""
  echo "請選擇要執行的功能："
  echo "  1) 新增借用"
  echo "  2) 查詢借用紀錄"
  echo "  3) 使用統計"
  echo "  4) 取消借用"
  echo "  5) 離開系統"
  echo ""
  read -p "請輸入選項編號 (1-5)： " choice

  case $choice in
    1)
      read -p "日期 (例如 2026-07-15)： " d
      read -p "時段 (例如 09:00-10:00)： " t
      read -p "項目 (例如 A會議室)： " i
      read -p "借用人： " n
      read -p "部門： " dept
      ./scripts/add_booking.sh "$d" "$t" "$i" "$n" "$dept"
      ;;
    2)
      read -p "請輸入查詢關鍵字（會議室/部門/日期皆可）： " kw
      ./scripts/search_booking.sh "$kw"
      ;;
    3)
      ./scripts/stats_booking.sh
      ;;
    4)
      read -p "請輸入要取消的借用關鍵字（建議格式：日期,時段,項目）： " kw
      ./scripts/cancel_booking.sh "$kw"
      ;;
    5)
      echo "👋 系統已離開，今日工作辛苦了！"
      break
      ;;
    *)
      echo "⚠️ 請輸入 1 到 5 之間的數字。"
      ;;
  esac

  echo ""
  read -p "按下 Enter 鍵返回主選單..." dummy
done
```

存檔離開，賦予執行權限：

`chmod +x scripts/booking_manager.sh`{{execute}}

## 🔹 拆解這段腳本新出現的兩個觀念

- `while true; do ... done`：一個會「不斷重複」的迴圈，讓使用者選完一個功能、按 Enter 之後，自動回到選單，不用每次都重新執行指令
- `read -p "提示文字： " 變數`：讓腳本暫停下來，等使用者打字輸入內容，並把輸入的內容存進這個變數裡，這就是讓你的腳本能跟「真人」互動的關鍵

> 💡 因為這個選單腳本需要你親手在鍵盤上打字互動，建議在自己的電腦或伺服器上實際執行 `./scripts/booking_manager.sh` 來體驗完整流程；在本練習平台上，前面 26~29 站個別測試過的功能已經足以證明系統正常運作。

你已經做出一個真正能用的系統了，以下是展示時的建議流程：

3. **現場示範新增一筆借用**：讓主管親眼看到一行指令幾秒鐘完成登記。
