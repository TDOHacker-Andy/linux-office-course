# Step 2：我是誰？我在哪？

每次走進一個新環境，你的本能反應大概是：「我現在是什麼身分？」「我人在哪裡？」終端機的世界也一樣，我們從這兩個最基本的問題開始。

## 🔹 指令 1：我是誰？

`whoami`{{execute}}

這個指令的名字非常直白——*Who Am I*（我是誰）。執行後，畫面會印出你目前登入的「帳號名稱」。

> 💡 你可以把「帳號」想成你的員工證——它代表「系統認定現在操作電腦的人是誰」。

## 🔹 指令 2：我在哪裡？

`pwd`{{execute}}

`pwd` 是 *Print Working Directory*（印出目前所在的工作目錄）的縮寫。執行後你會看到類似這樣的結果：

```
/root
```

這一串文字叫做**路徑（Path）**，代表你目前位置在系統裡的「地址」。

## 🗂️ 路徑是什麼？用辦公大樓來比喻

想像整台電腦的檔案系統，是一棟超大的辦公大樓：

- 最頂層的「大樓本身」叫做**根目錄**，符號是 `/`
- 每往下走一層樓，就是一個資料夾（在 Linux 裡也叫**目錄**）
- `/root` 的意思就是：從大樓的最外面（`/`）走進去，進入一個叫做 `root` 的房間

你現在站的位置 `/root`，其實就是你這個帳號專屬的「個人辦公室」，在 Linux 的術語裡叫做**家目錄（Home Directory）**。
