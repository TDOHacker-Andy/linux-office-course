# Step 12：找東西——萬用字元與 find

辦公室裡常常遇到這種情況：「我記得這份檔案的名字裡有『2025』，但確切放在哪個資料夾我忘了。」這一站教你怎麼快速找到它。

## 🔹 萬用字元 `*`：代表「任何字串」

`*` 這個符號，在 Linux 裡代表「不管是什麼內容，通通算」。我們先確認一下目前位置有哪些檔案：

`ls`{{execute}}

`ls archive`{{execute}}

來試試看，只列出 `archive` 資料夾裡，檔名以 `summary` 開頭的檔案：

`ls archive/*/summary*`{{execute}}

這行指令的意思是：「不管 `archive` 底下的子資料夾叫什麼名字（用第一個 `*` 代表），只要裡面有檔名以 `summary` 開頭的東西（用第二個 `*` 代表後面隨便接什麼），都列出來。」

再試一個常見用法——只列出所有 `.txt` 檔案：

`ls archive/*/*.txt`{{execute}}

## 🔹 指令：find——更強大的全面搜尋

萬用字元 `*` 只能在你「知道大概位置」的情況下使用。如果你完全不記得檔案在哪個資料夾，需要從某個起點開始「整層整層往下翻找」，這時候要用 `find`：

`find . -name "*.txt"`{{execute}}

拆解一下這行指令：

- `find`：搜尋指令
- `.`：從「目前所在的這個資料夾」開始找（還記得 Step 4 教過 `.` 代表目前位置嗎？）
- `-name "*.txt"`：搜尋條件，檔名只要符合 `*.txt`（也就是任何以 `.txt` 結尾的檔案）都算

你會看到 `office_drill` 底下所有層級、所有資料夾裡的 `.txt` 檔案，一次全部被列出來，不管它們藏多深。

## 🔹 在大樓裡從根目錄開始找

也可以指定別的起點，例如搜尋整個 `office_drill`：

`find /root/office_drill -name "summary.log"`{{execute}}

## 🆚 萬用字元 `*` 跟 `find` 該用哪一個？

| 情境 | 該用 |
|---|---|
| 我大概知道檔案在哪個資料夾附近 | 萬用字元 `*`（搭配 `ls`） |
| 我完全不記得位置，要從某個起點整層翻找 | `find` |
