# Step 3：看清單——這個房間裡有什麼？

知道自己在哪裡之後，下一步當然是看看「這個房間裡放了什麼東西」。

## 🔹 指令：ls

`ls` 是 *List*（列出清單）的縮寫：

`ls`{{execute}}

你應該會看到一個叫做 `office_drill` 的資料夾——這是我們等一下要用來練習的「練習場」。

## 🔹 進階版：ls -l（看更詳細的資訊）

剛剛的 `ls` 只告訴你「有什麼」，但沒告訴你「這是檔案還是資料夾」「多大」「什麼時候修改的」。加上 `-l`（*Long format*，詳細格式）：

`ls -l`{{execute}}

你會看到類似這樣一行：

```
drwxr-xr-x  3 root root 4096 Jun 30 12:00 office_drill
```

別緊張，我們先抓重點看：

- 最前面的 `d`：代表這是一個**資料夾**（Directory）。如果是檔案，這個位置會是 `-`
- 中間那串 `rwxr-xr-x`：是這個資料夾的「權限」，我們會在模組 E 花一整個段落仔細拆解，現在先眼熟就好
- `root root`：分別是「擁有者」和「所屬群組」
- `4096`：檔案大小（單位是位元組）
- `Jun 30 12:00`：最後修改時間
- 最後面：檔案或資料夾的名稱

## 🔹 進階版：ls -a（連隱藏檔案都看到）

Linux 裡有些檔案是「隱藏」的（檔名開頭是 `.` 的就是隱藏檔），平常 `ls` 不會顯示它們：

`ls -a`{{execute}}

你會看到多了 `.` 和 `..` 這兩個東西，這不是亂碼，它們代表：

- `.`：目前所在的這個資料夾本身
- `..`：上一層資料夾（我們下一站就會用到它）

## 🔹 也可以混合使用選項

`ls -la`{{execute}}

這代表同時套用 `-l`（詳細格式）跟 `-a`（顯示隱藏檔），Linux 的選項大多可以這樣自由組合。
