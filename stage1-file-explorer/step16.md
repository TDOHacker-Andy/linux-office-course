# Step 16：看懂 rwx 暗號——權限是怎麼回事

Linux 是一個「多人共用」的系統設計（即使你現在是一個人用，骨子裡的設計邏輯仍然是這樣）。因此每一個檔案、每一個資料夾，都會記錄「誰可以做什麼事」，這就是**權限（Permission）**。

## 🔹 先看一次完整的權限字串

`ls -l taiwan_customers.txt`{{execute}}

你會看到一行類似這樣的結果：

```
-rw-r--r-- 1 root root 312 Jun 30 12:00 taiwan_customers.txt
```

我們把最前面那串 `-rw-r--r--` 拆開來看。

## 🔹 第一個字元：這是檔案還是資料夾？

- `-`：代表這是一個**檔案**
- `d`：代表這是一個**資料夾**（Directory）

## 🔹 後面 9 個字元：分成三組，每組 3 個字

`rw-r--r--` 要拆成三組，每組三個字母：

```
rw-  r--  r--
 │    │    │
擁有者 同群組 其他人
```

每一組的三個字母分別代表：

| 字母 | 意思 |
|---|---|
| `r` | *read*，可以讀取（打開來看內容） |
| `w` | *write*，可以寫入（修改、刪除內容） |
| `x` | *execute*，可以執行（如果是程式或腳本） |

如果某個位置是 `-`（而不是 r、w、x），代表「沒有這項權限」。

## 🔹 實際解讀剛剛看到的 rw-r--r--

- **擁有者**（`rw-`）：可以讀、可以寫，不能執行
- **同群組**（`r--`）：只能讀，不能寫、不能執行
- **其他人**（`r--`）：只能讀，不能寫、不能執行

白話翻譯：**這份檔案，只有它的主人能修改內容，其他人（包含同部門同事）都只能看，不能改。**

## 🔹 練習：看資料夾的權限

`ls -ld archive`{{execute}}

你應該會看到開頭是 `d`（代表資料夾），後面接著類似 `rwxr-xr-x` 的權限字串。請試著自己拆解看看：擁有者可以做什麼？同群組可以做什麼？其他人可以做什麼？

> 💡 小提醒：資料夾的 `x` 權限意義跟檔案不太一樣，它代表「可以進入這個資料夾」（也就是可以 `cd` 進去）。沒有 `x` 權限的資料夾，即使有 `r` 權限，你也無法真正走進去查看裡面的東西。
