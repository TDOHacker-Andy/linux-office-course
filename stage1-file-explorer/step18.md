# Step 18：借用超級英雄的力量——sudo

有些操作（例如等一下模組 F 要學的「新增帳號」），一般權限是完全做不到的，必須借用系統管理員的權限才能執行。這一站學的 `sudo`，就是你的「臨時超能力借用卡」。

## 🔹 指令：sudo

`sudo` 是 *SuperUser DO* 的縮寫，意思是「以系統管理員的身分，執行後面接的這個指令」。用法是：

```
sudo 原本的指令
```

我們來做一個對照實驗。先建立一個只有系統管理員才能寫入的測試檔案：

`sudo touch /etc/test_admin_only.txt`{{execute}}

`sudo chmod 600 /etc/test_admin_only.txt`{{execute}}

現在嘗試「不用 sudo」直接修改它的內容：

`echo "測試文字" > /etc/test_admin_only.txt`{{execute}}

你應該會看到 `Permission denied`（權限被拒絕）——因為這份檔案的權限被設成只有真正的擁有者能寫入，而你目前的身分不符合。

現在加上 `sudo` 再試一次：

`sudo bash -c 'echo "測試文字" > /etc/test_admin_only.txt'`{{execute}}

確認寫入成功：

`sudo cat /etc/test_admin_only.txt`{{execute}}

這次因為借用了管理員權限，所以即使檔案被鎖住，依然可以正常寫入跟讀取。

清理一下測試用的檔案：

`sudo rm /etc/test_admin_only.txt`{{execute}}

## ⚠️ sudo 的使用心法

`sudo` 是一把「萬能鑰匙」，威力強大，使用時請務必謹慎：

1. **每次使用前，先確認後面接的指令真的是你要的**——尤其是搭配 `rm` 的時候，因為借用管理員權限後，連系統重要的檔案都能被刪除。
2. **能不用 `sudo` 就不要用**——只有在一般權限真的做不到時，才需要借用。
3. `sudo` 不是用來「圖方便」的，而是用來處理「真的需要管理員等級權限」的特定任務，例如：新增帳號、安裝套件（模組 G 會學到）、修改系統設定檔。
