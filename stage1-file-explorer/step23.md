# Step 23：安裝好用小工具——apt install

## 🔹 指令：apt install——安裝指定的軟體

語法是 `sudo apt install 軟體名稱`：

`sudo apt install -y tree`{{execute}}

- `install`：安裝
- `-y`：自動回答「是」，跳過安裝過程中的確認詢問（在練習環境很實用，正式工作時你也可以選擇不加，自己手動確認一次）
- `tree`：要安裝的軟體名稱

## 🔹 馬上使用剛裝好的工具

`tree` 可以把資料夾結構畫成一目了然的樹狀圖，比一層一層 `cd` 進去 `ls` 方便多了：

`tree office_drill`{{execute}}

是不是一眼就能看懂整個資料夾的階層結構？這在你要跟同事或主管說明檔案放置邏輯時非常實用。

## 🔹 再安裝一個有趣又實用的工具

`sudo apt install -y figlet`{{execute}}

`figlet` 可以把文字變成放大的 ASCII 藝術字，常被拿來在腳本執行完畢時顯示一個顯眼的提示訊息：

`figlet "Hello Linux"`{{execute}}

> 💡 這個工具在模組 H 的期末專題裡會派上用場——我們會用它讓「借用登記成功」的訊息變得更顯眼。

## 🔹 如果想移除已安裝的軟體

雖然本課程不會用到，但你應該知道有這個指令存在：

```
sudo apt remove 軟體名稱
```

## 🆚 apt update 跟 apt install 的差別

| 指令 | 作用 |
|---|---|
| `apt update` | 更新「軟體目錄清單」，確認有哪些軟體、最新版本是什麼 |
| `apt install 名稱` | 真正把指定的軟體「安裝」到你的電腦裡 |

兩者通常會先後搭配使用：先 `update` 確保清單是最新的，再 `install` 真正安裝。
