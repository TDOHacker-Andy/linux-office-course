

恭喜你走到最後一關！在第一關時，我們在畫面的暗號裡學到了：
* **`$`** 代表一般受限員工（User 權限）
* **`#`** 代表最高通行權的管理員（Root 權限）

目前你在右邊黑色視窗裡看到的是 `#`（因為我們預設是以最高管理員登入）。但是在企業的實際運作中，為了資訊安全，我們平常會用「一般員工」的身分工作，只有在需要安裝軟體或修改系統時，才會暫時切換成「總裁（管理員）」身分。

我們來練習如何在終端機裡優雅地切換身分！

---

### 1. 體驗受限：切換成一般員工身分
在 Linux 中，切換使用者（Switch User）的指令叫做 `su`。我們現在把自己降職成這台電腦的預設一般員工 `ubuntu`：

```bash
su - ubuntu
```{{execute}}

> 💡 **仔細看！右邊黑視窗的提示字變了：**
> 1. 左邊的帳號從 `root` 變成了 **`ubuntu`**。
> 2. 最右邊的權限符號從 `#` 變成了 **`$`**！
> 
> 這代表你現在已經脫下總裁西裝，變成了一般受限的員工。你可以試著輸入 `whoami` 確認，系統會回答你 `ubuntu`。

---

### 2. 請總裁出來（Sudo）：用最高權限執行單一指令
現在你是一般員工了，如果主管突然叫你翻閱一些只有總裁能看的系統安全日誌（例如 `/etc/shadow` 檔案），你直接看會被系統擋下來。
這時我們不需要重新登入，只需要在指令前面加上 **`sudo`**（SuperUser Do），代表「請最高管理員幫我執行這件事」：

```bash
sudo cat /etc/shadow | head -n 3
```{{execute}}

> 💡 **這行指令代表什麼意思？**
> `sudo` 會暫時幫你借來總裁的印章。畫面上印出了原本一般員工絕對看不了的系統密碼陰影檔（我們用 `head -n 3` 只看前三行），這就是 `sudo` 在 Linux 日常運維中最重要的安全防線！

---

### 3. 功成身退：優雅地離開終端機
任務完美搞定，業務部也恢復了秩序。下班離開前，我們要優雅地關閉這個 Shell 祕書。請輸入以下指令並按下 **Enter**：

```bash
exit
```{{execute}}

> 💡 **它會發生什麼事？**
> 它會讓你「登出」目前的 ubuntu 身分，回到原本的 root 身分。如果再打一次 `exit`，這個終端機視窗就會安全地關閉。

---

# 🎉 恭喜你！全關卡完美通關！

你已經成功從一個看到黑底白字視窗會害怕的 Linux 新手，蛻變成能夠熟練運用：
1. **`whoami` / `pwd` / `ls`** 進行情報搜集
2. **`cd` / `mkdir`** 進行空間瞬移與影分身建檔
3. **`mv` / `cp` / `rmdir`** 進行辦公桌大掃除
4. **`cat` / `grep` / `| (管線)`** 進行大數據百步穿楊搜尋
5. **`su` / `sudo`** 掌控系統安全權限

的行政救火隊總管！這套基本功將成為你未來不論是搞網頁、做開發、還是管伺服器時，最堅實的護城河。

請點擊右下角的 **FINISH** 按鈕，順利結束這趟 Linux 驚奇之旅吧！
